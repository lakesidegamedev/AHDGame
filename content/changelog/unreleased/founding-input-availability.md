## What changed

- When an NPP company or a corporation on autopilot looks for a new market, it now checks how much of each input the plant's state actually received last turn. If the plant's scarcest input arrives at less than half of what it needs, that market is skipped and the next best one is chosen. A farm is no longer opened into a fertilizer shortage just because food sells well.
- When choosing which recipe to build, a recipe with starved inputs is passed over for one that can run. A farm whose standard recipe cannot get fertilizer builds a lighter-fertilizer recipe instead, if food is short enough to justify it.
- Neither NPP companies nor autopilot add capacity to an existing plant whose run was cut below half by missing inputs last turn. Worn capacity is still replaced.
