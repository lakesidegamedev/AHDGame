title: "Canada only appears in worlds started with it"
summary: >-
  Worlds that were already running before Canada was added carry on exactly as
  before, without a Canada they never set up.
tags: [world]
badges: [patch]
areas: [engine]
---

Canada is playable in new 2027 worlds. Worlds that were already running before
this release, including the live world, never set Canada up: it has no
provinces, budget, parties or politicians there. Those worlds now leave Canada
out entirely, instead of trying to run it each turn as an empty country.
