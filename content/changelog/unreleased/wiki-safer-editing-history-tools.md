## What changed

- When you edit a page that is already live, the current version stays up until
  a moderator approves your edit. Before, the whole page disappeared while it
  waited.
- A failed save keeps your text in the editor and says what went wrong. Unsaved
  text is kept in your browser and offered back if you reload.
- Authors and moderators get a History view for each page, with a comparison of
  any two versions. Moderators can restore an older version.
- New Politician, Party and Corporation templates add an infobox on the right of
  the page.
- Writers can add an election result box, a party seat chart or a corporation
  share price chart with a short tag. A wrong id shows a note only to the writer.
- Type `[[` in the editor to search for a page and link it. The preview now looks
  like the published page.
- Moderators see pending images inline, can compare an edit with the live text,
  can add a note when approving, and have an approval log filtered by moderator
  or page.
