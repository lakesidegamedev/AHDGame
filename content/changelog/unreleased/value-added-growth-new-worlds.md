## What changed

- In a freshly created world, regional growth is measured on value added: output minus the inputs a sector buys. Industries that pass most of their output on to others no longer count that output twice.
- Growth in a single industry now moves the regional figure by what that industry adds, so a technology boom counts for more than the same lift in retail.
- A world that is already running keeps the old measure, so nothing shifts in play.
