date: 2026-11-25
title: "Buttons are flat"
summary: >-
  Buttons no longer carry a glow or a gradient in the classic interface or the
  Command 1953 theme. Each button is one solid colour.
tags: [ui, themes]
badges: [patch]
areas: [frontend]
---

In the classic interface, main buttons no longer glow and card-coloured
buttons no longer pick up the faint gradient used on panels. Focus rings keep
their solid outline without the glow around it.

In the Command 1953 theme, buttons no longer glow on hover or focus. The
theme's green phosphor text is unchanged.
