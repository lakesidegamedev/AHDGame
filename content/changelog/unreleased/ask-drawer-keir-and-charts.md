## What changed

- Charts and maps in an answer are drawn in the drawer instead of showing as
  raw code. Charts follow the game's light or dark theme, show values on
  hover, and can show their data as a table.
- Diagrams the drawer cannot draw yet link to the full Ask Keir site.
- Each answer shows the research steps behind it, any live game data it read,
  a link to the report page for report answers, and a note when the daily
  chart allowance is spent.
- When an answer came from code only, a button asks the same question again
  with live game data.
- Keir sits in the drawer and on its tab. He waves when you open it, listens
  while you type, thinks while he researches, talks while the answer arrives,
  and looks alarmed if something goes wrong.
- The drawer is now titled Ask Keir.
