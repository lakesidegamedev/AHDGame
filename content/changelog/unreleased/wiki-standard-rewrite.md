## What changed

- Every system page now opens with what the system is and why it matters,
  then how it works with a table of the numbers you plan around.
- Each system page has at least one worked example with real numbers, and a
  What you can do section that says which actions you have and where to find
  them.
- A Connections section lists what drives each system and what it affects,
  linked both ways, so you can follow cause and effect across the game.
- Each page says which countries, eras or worlds it applies to, when it was
  last checked against the game, and links the full technical rules.
- Common player questions about each system are now answered on its page.
